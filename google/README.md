# Серверная часть (Google-таблица)

Файлы:
- `Шаблон_Заявки_Google.xlsx` — шаблон таблицы (листы Пользователи, Объекты, Позиции, Заявки, Строки, Журнал, Инструкция).
- `Code.gs` — скрипт Google Apps Script (Расширения → Apps Script).

Вход в приложение — по фамилии (без пароля); доступны только объекты из столбца «Объекты» листа «Пользователи».
Адрес развёртывания (`.../exec`) вписывается в `config.json`: `{"api": "https://script.google.com/macros/s/XXXX/exec"}`.
Пока `api` пустой, приложение работает локально.
