# Серверная часть (Google-таблица)

Файлы:
- `Шаблон_Заявки_Google.xlsx` — шаблон таблицы (листы Пользователи, Объекты, Позиции, Заявки, Строки, Журнал, Инструкция).
- `Code.gs` — скрипт Google Apps Script (вставляется в Расширения → Apps Script).

Порядок установки — на листе «Инструкция» шаблона. Адрес развёртывания (`.../exec`) вписывается в `config.json` в корне репозитория:
`{"api": "https://script.google.com/macros/s/XXXX/exec"}`. Пока `api` пустой, приложение работает локально (как раньше).
